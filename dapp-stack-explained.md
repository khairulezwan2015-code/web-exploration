# How the web3 stack works

## 1. What does the frontend do in a dApp?
Usually does UI/UX stuff, wallet connection, listening to events on chain data, and similar.

## 2. What does a backend do in a dApp?
Indexing, off-chain data, oracles, notifications, APIs, and similar.

## 3. What does a database do in a dApp?
Store information.

## 4. What's one thing a smart contract can do that a database cannot?
Trustless execution that no one can interrupt.

## 5. What's one thing a database can do that a smart contract should not?
Store images, big files, and much more.
